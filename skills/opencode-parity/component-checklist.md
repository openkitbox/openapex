# 组件深挖清单

对一个上游组件或功能逐项填写。每一项两侧都要有 `file:line`；没找到写"无"，没读写"未核实"。

## 1. 状态

idle、hover、focus、expanded/collapsed、selected、disabled、loading、error、empty。
对每个状态：上游怎么进入、怎么退出、外观变化是什么（颜色 token、文字、图标）。

## 2. 输入

- 键盘：快捷键（含 leader 序列）、方向键、Enter/Esc、Tab。
- 鼠标：点击、双击/三击、悬停、拖选、滚轮、右键。
- 粘贴：文本、路径、图片。
- 点击处理前是否检查"当前有选区"（上游 `getSelectedText()` 守卫）。

## 3. 渲染

- 每个展示的数据字段，来自哪个 API 字段或事件。
- 每个元素用的主题 token（对照 `theme/*.ts`）。
- 布局：宽度分配、截断规则、换行、缩进、边框与间距。
- 不同终端能力下的降级（无色、16 色）。

## 4. 边界

空数据、超长文本、宽字符（中日韩、emoji）、窄终端、很多条目（滚动与折叠）、并发更新、流式中途的状态。

## 5. 副作用

toast、剪贴板、导航或路由变化、持久化（历史、配置）、发出的 API 调用、订阅的 SSE 事件。

## 6. 缺口报告

| 缺口 | 上游 file:line | ox file:line | 用户可见 | 体量 | 决策 |
|---|---|---|---|---|---|

- 用户可见：是/否（只影响内部结构的不算缺口）。
- 体量：S（<50 行）、M、L。
- 决策：对齐 / 有意偏差（写原因，回填台账）/ 暂缓。
